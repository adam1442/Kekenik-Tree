# Changelog

All notable changes to this project are documented here. The format is based on
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project follows
[Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added
- **UV Mapping** tab on Branch (and the Extensions UV list): Style (Unrestricted / U locked / U and V locked), Extension style, U (Absolute, + Relative, Offset with variance, Fractional Enable / Auto / Value, Twist Amount / Random flip), V (Style Absolute / Relative (keep aspect ratio) / Relative, Anchor, Scale, Skew correction, Pinch, Offset with variance) and Tiling (Style Tiling / 0-1 patches choose one / use all, Optimize segments, V tolerance, Seed). The Branch and Extension **Material** lists have Material (material, Material Set or Inherited), Weight and, with a patch style, a patch options button (UV Area, Placement). Patches keep UV inside their UV Area and double the vertices along seams. Formulas are in `docs/PARAMETERS.md`; old projects keep their look (node version 5).
- **Displacement** tab of Trunk / Branch / Root: *Main* (Source Noise / Material Height map / Displacement asset, Radial amount, Length amount, Sharpness curve, Mapping Use UVs / Fit to geometry, U scale, V scale, Seed), *Fine* (Amount, Sharpness, Scale: normal noise), *Shape* (Amount, Twist, Scale, Seed: creases along the spine) and *Flares* (Radius, Noise scale, Height, Pinch, Angle, Seed: trunk bases / roots). Applied after welding with a fade past the weld rings, at tips and at junctions; seamless at U = 0 / 1; rings and sides are added automatically (Subdivision). Older projects keep their asset Amount. Pure logic in `src/generators/displace/`.
- Skin > **Splits** on Trunk / Branch / Root (Chance, Balance, Seed; Spread, Expand: Side 1 / Side 2; Smooth: Inner, Outer): a branch can end in two fused open ends with the cross-section area conserved. Generation > Extend parent now really uses **Split 1**, **Split 2**, **Skinny**, **Fat** (and Any = every open end, Breaks only = real breaks); it also works under a Trunk. New **Branch > Extensions** groups: Spine (Length scale, Spread with a profile curve), Skin (Radius with curve, Normal smooth, Displacement scale) and UV (Extension style list). Extensions continue their parent end without a weld ring, collar or cap. The **Cap** now closes exactly the open ends (broken branches and split sides) and follows Extend parent. Pure logic in `src/generators/split/`.
- Skin > **Welding > Blend** (Enabled, Texture, Texture scale, Contrast, Noise, Lighting curve): the bark map of a welded child fades into the map of its parent around the weld (per-vertex `weldBlend` / `weldParentUV` channels, two map samples mixed in the bark shader; other materials ignore it).
- Skin > **Radius** (Absolute, + % of parent, Clamp to parent, Length compensation, Length kill ratio, Light seam reduction, Roll, Smooth), **Clamp** (Min, Max), **Squash** (Amount, Rotate; welded children follow the flattened parent) and **Type & Visibility** (Type: Polygons / Spine only, the SubD entries are listed as not yet available; Visibility curve: branches above 0.5 get geometry). Pure logic in `src/generators/skin/`.
- Skin > **Welding** on Branch and Root: *Enabled* fuses the base of a child into the surface of its parent (the base ring lies exactly on the parent skin at any angle, a smooth blend of rings leads to the plain branch, normals fade from the parent's to the branch's), *Keep* (curve over the model height; welds below 0.5 are dropped), *Keep failed*, *Force ray casts* (rays against the real parent tube instead of the procedural cone), *Offset* (length of the weld part in branch radii) and **Spread** (*Amount*, *Upper scale*, *Lower scale*: widening at the weld site, a web where branches meet). Failed welds remove the branch unless *Keep failed* is on. The number of rings uses Segments > Length > Weld scalar. Off by default; pure logic in `src/generators/weld/`.
- Spine > **Noise** has *Early* (Amount, Turbulence, **Threshold** with a profile curve: where the early noise starts and ends) and *Late* (Amount, Turbulence, Smooth, Seed) blocks; the Late Seed changes only the late noise. New Spine sections **Jink** (Amount, Absolute, + Relative, Uniformity, Seed: straight runs), **Path** (Amount, Profile curve = one tile, Twist, Length, Offset with variance) and **Break** (Chance, Spot, Seed). Broken branches write an `openEnd` skeleton attribute that Extend parent > Breaks only (and Caps) read. Pure logic in `src/generators/spine/` (`noiseMath`, `jinkMath`, `pathMath`, `breakMath`).
- **Segments** tab on Trunk / Branch / Root / Spine: Accuracy (exact points of the high-resolution spine), Influence, Scalar; Length (Style Default / Legacy, Absolute, + Relative, Relative basis: Length only / Length/radius ratio / Parent's length segments, Weld scalar, Optimization) and Radial (Absolute, + Relative, Relative basis: Radius / Parent's radial segments). The radial count is stored per branch (`radialSides` skeleton attribute).
- Spine > Length: Match one V tile, Stop shape control, Shape scale; Orientation: Unify, Alignment blends a random up with the world up, Weld start for Spine only branches; Parent Curl Up / Right / Out rotate around the parent's axes; Zigzag Segment length (Absolute with curve, + Relative); Prune Interior / Up / Down / General / Ground are 0..1 strengths with curves.
- Shared Generation properties on every generator: **Boundaries** (First, Last, Clip removes nodes pushed outside the range), **Common** (Active over the level of detail, Pass with an error badge when lower than an ancestor, Rotation, Position, Sink with variance, Pruning curve), **Extend parent** (None, Any, Split 1, Split 2, Skinny, Fat, Breaks only, Bottom + Count; Branch / Cap / Leaf / Batched leaf), **Knockout** (Amount + Resolution), **Force containers** (Include / Exclude by Force node name; Force nodes got a *Volume* section: Sphere or Box), **More** (Click place, Mesh alignment, Size scalar that is handed down to all children) and **Masks** (any number of masks from the Masks panel). The pure logic lives in `src/generators/common/`.
- Generation modes for every generator (Trunk, Branch, Root, Spine, Leaf, Batched Leaf, Mesh Instance, Cap, Cluster): Absolute, Proportional, Absolute steps / Proportional steps (Steps, Per step, Spread, Roll, Balance), Phyllotaxy (Internode length in metres from Last towards First; Style Opposite distichous / decussate / random, Alternating distichous / random, Whorled; Children per node, Spread, Spiral, Limit, Align style), Interval (Frequency with a profile curve, Count, Spread, Spiral, Limit, Align style, Balance), Bifurcation (Count, Threshold, Spread), Flood and Parent. Only the parameters of the chosen mode are shown; *Classic* is listed as a disabled legacy entry. The layouts live in the pure module `src/generators/modes/` and every node publishes its `side` (+1 / -1) and `groupIndex`.

### Changed
- The Skin *Spine only* switch is now the Skin > **Type** list; old projects are migrated on load.
- Spine: Late noise Smooth now low-pass filters the noise and removes it completely at 1; Break Spot may go from 2 % to 99 % of the length; Break chance / spot moved from *Splits & Termination* to the *Break* section (same ids, old projects load unchanged); Extend parent > Breaks only uses the exact open-end flag instead of the tip radius heuristic when the parent carries it.
- Spine: Straightness now removes noise fully at the base and not at all at the tip; Shape scale scales the crown shape of the length (it no longer scales curvature and noise); Ground prune removes a branch that intersects the ground plane instead of cutting it; `lengthRelative` is folded into + % of parent, `matchOneVTile` is a checkbox and the Skin `lengthSegments` override moved into Segments > Length (old projects are migrated on load).
- The old scalar *Pruning* is replaced by a Pruning curve; projects that used it get the same random removal through Knockout. *Clip* removes nodes instead of shrinking the range (default inset 0). The Tree node's *Size scalar* now scales the whole plant. Active now honours its curve in Leaf, Frond, Decoration, Mesh Instance and Cluster too. Sink now has variance on Branch / Trunk children.
- Old projects are migrated on load: `whorled` is now Absolute steps, the golden-angle Phyllotaxy becomes Alternating (distichous) with a Spiral, Bifurcation keeps its count. Built-in presets use the new parameters. Absolute mode now also publishes a `side` attribute (derived from the roll).

### Fixed
- Wind could not be switched off after opening an example or a project with a Wind node on the Tree: the toolbar popover, the Wind panel, Properties > Global Wind and the wind arrow edited the project settings, which the Wind node silently overrides. They now edit the effective source (the Wind node, as an undoable change, or the project settings when there is no node) and show its values.
- Edit Mesh dialog, shared dialog buttons/footers (info, prompt, choice, Export, LOD editor) and a few inspector widgets were missing their stylesheet rules in the published build; the rules now live in `ui/theme/editmesh.css` and `panels.css`.

### Added
- Frond *Left-Right Variance* (Amount, Seed: each half reacts independently to Curl, Fold and Gravity) and *Section Variance* (Favor Outliers; Amount / Offset for Gravity, Fold, Curl and Roll per mesh section painted in the cutout editor).
- Frond *Lighting* tab: Style Global / Local, Smooth, Alignment, Spread, Parent puffiness (Anchor incl. the new *Origin*, Amount) and Up / Right / Out adjustments, built on `applyLeafLighting`.
- Frond wind: Weight (curve), Cross, Boost (curve) and Ribs (Apply branch wind, Weight), written into the existing per-vertex wind weights; the base stays static.

### Changed
- Frond generator rebuilt on ribs: a left and a right rib runs across the parent spine at every length segment, and the cutout mesh of the assigned material (or a plain ribbon) is mapped onto them. The length always comes from the parent spine. New Shape tab (Unification, Height: Amount / Offset / Gravity / Fold / Curl / Roll, Boundary: Start / End, Scale: Width / Height), Segments tab (Accuracy, Width: Absolute / + Relative), Forces tab (Gravity, Up / Down, Ancestor with strength curves, Align) and Material: Flip, Two sided, Mesh Index / Resolution. Older Frond graphs and the built-in presets are migrated automatically (the old Droop becomes the Gravity force; Arch, Twist, Crease, Sink and length scaling were dropped).

### Added
- Leaf generator *Lighting* tab: Style (Global / Local) and a normal-editing pass run after deformation (Smooth, Parent puffiness with Global / Deep / Intermediate / Local / None / Height / Surface X-Y-Z anchors, Anchor shift, Puffiness, Unify, Up / Right / Out adjustments with variance, World up). Global style reads a shared group on the Tree node (new *Lighting* tab). The pass is `applyLeafLighting` (reusable by the Frond). The old Spherize / Bend controls did nothing and were removed.
- *Batched Leaf* node: the Leaf evaluator without Mesh LOD offset, vertex-noise Seed, Unify and World up, always at the highest detail, merged into one slot per material (`mergeByMaterial`) with an index table (`MeshData.parts`) that resolves every triangle back to its source leaf.
- Leaf generator *Leaves* tab: Use actual size, Size (curve + variance) and +% of parent, Weld / Keep failed welds, Cross, Fix winding, Flip with Classic / Synchronized initial orientation, the Type list, Local orientation (3D anchor style, Unification, Sky influence, Fold, Align, Face), Sensitivity → Parent (Amount, Anchor, Sky) and Final adjustments (Up, Right, Out). Interval / Phyllotaxy placement now publishes a per-branch `side` attribute and generators publish ancestor chains for the Global / Deep / Intermediate / Local anchors. The old Skin › Size *Scale* is migrated to *Size*; the Type list moved from Material › Leaves to Leaves › Type.
- Leaf generator *Deformation* tab (Height from the material Height map, Fold, Curl, Twist, Vertex Amount / Noise / Seed, Scale X / Y / Z; curves and variance) and *Resolution* tab (Size increase % curve, Mesh LOD curve, Mesh LOD offset). The pivot stays fixed, attachment anchors follow the deformed leaf, sparse meshes are subdivided at high detail, and the viewport LOD selector switches mesh versions and sizes live. Defaults reproduce the previous result.
- A material can own several cutout meshes (`MaterialDef.meshes`, first = Primary). The Materials panel *Cutouts/Meshes* tab lists them with thumbnails, a Primary badge, move up/down, duplicate, delete, per-mesh Edit mesh… and a preview of the selected mesh. Older projects migrate automatically.
- `MaterialSlotList` widget (Material / Mesh / Weight rows with pick probabilities, Material Sets, Any / Primary / Not primary) for Leaf, Frond, Decoration, Cluster and Mesh Instance; Frond uses the chosen cutout mesh instead of the ribbon, Mesh Instance mixes meshes per instance.
- `npm run build:check` / `scripts/check-built-css.mjs`: post-build guard that verifies the built CSS against `scripts/css-contract.json`; runs in the CI, deploy and release workflows.

## [1.0.0] - 2026-11-13

Initial public release.

### Added
- Node-based procedural plant generation with live, cached and cancellable evaluation, undo/redo, node templates, autosave and crash recovery.
- Generators: Trunk, Branch, Root, Spine, Frond, Leaf, Cap, Decoration and Mesh, with Split, Knot and Cluster helpers; per-parameter variance and curves along the parent.
- Forces (gravity, directional, phototropism, attractor, vortex, turbulence, curl and more) and hierarchical GPU wind with a timeline.
- Materials with texture maps, material sets, masks, alpha-coverage mips and viewport quality options (MSAA, SMAA, TAA, FXAA).
- Cutout / mesh editor with outlines, straighten axes, attachment anchors and LOD meshes.
- Curve and color-ramp editor with presets, tangent modes and a freehand draw tool.
- Height-map displacement of generated branches.
- LOD editor with viewport preview.
- Export to GLB, glTF, OBJ, PLY and STL with LODs, baked ambient occlusion and billboard impostors.
- Dockable, tabbable and floating panels with saved layouts; instance-level Node mode.
- Species library of 16 presets, user presets and `.ktree` project import/export.
- Welcome screen, interactive tour, keyboard shortcut sheet and preferences (UI scale, navigation scheme, autosave, performance mode).
- GitHub Actions for CI, GitHub Pages deployment and tagged releases.
