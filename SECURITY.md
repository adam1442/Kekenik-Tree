# Security policy

## Supported versions

Only the latest release and the current `main` branch receive security fixes.

## Reporting a vulnerability

Please **do not open a public issue** for security problems. Email the maintainer privately:

**hossein.r.1442@gmail.com** — subject line `[Kekenik Tree security]`

Include a description, steps to reproduce (a `.ktree` project or file that triggers the problem is ideal), the affected version or commit, and the browser you used. You will receive an acknowledgement within a few days, and we will coordinate a fix and disclosure timeline with you.

## Scope

Kekenik Tree is a static, client-side application: it has no backend, accounts or telemetry and makes no network requests of its own. Relevant reports include, for example, malicious project/preset/image/mesh files that cause script execution, data exfiltration or denial of service in the browser, and vulnerabilities in bundled dependencies.
