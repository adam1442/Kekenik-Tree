# Kekenik Tree – User Guide

## Quick start (5 minutes)
1. **Open a sample project.** On start the Welcome window lists the six sample projects (Oak, Birch, Palm, Fern, Grass, Swamp) – click one. *File ▸ New* (and the project the app opens with) is empty: it holds the Tree node only, so add a Trunk or a Spine with `Tab`. Or use *Window ▸ Layout ▸ Library (presets)* and double-click a card (or drag it into the viewport).
2. **Look around.** Viewport: LMB orbit, MMB / Shift+LMB pan, wheel zoom, `F` frame, `Home` reset camera, `Alt+1…8` view modes (shaded, wireframe, normals, AO, skeleton …).
3. **Tweak.** Click a node in the *Generation* graph; the *Properties* panel shows its parameters. Hover a label for a description. Examples: Trunk ▸ *Length*, Branch ▸ *Number*, *Spread*, *Gravity*, Leaf ▸ *Width / Height*. `Shift+R` randomises the seed.
4. **Wind.** *Window ▸ Wind & Timeline*: set direction / strength and press play. Per-node *Wind* tabs set how much a trunk, branch or leaf reacts.
5. **Export.** *File ▸ Export…* (`Ctrl+E`) → format GLB, LOD levels, texture size, AO bake, impostor → *Export*. The result list verifies the file.

## Graph basics
Children grow upward from the parent. `Tab` / double-click adds a node; drag from a port to connect; `Del` deletes; `Ctrl+C/V/D` copy/paste/duplicate branches; `F2` renames; `A` fits; `Space+drag` pans.
Node types: **Trunk**, **Branch**, **Root**, **Spine**, **Split** (structure) · **Leaf**, **Frond**, **Cap**, **Cluster**, **Knot**, **Decal**, **Fin**, **Mesh** (surface) · **Forces** · **Material** · **Wind**.

## Parameters
Every row has: label (hover for help) · slider/number · optional `%` toggle (random variance) · optional curve button (vary along the parent). Orange bars mark modified values. A yellow `!` marks counts that will be slow.

## Decals and fins (surface details)

Both are placement generators: add them under a Trunk, Branch or Root and use the shared **Generation** tab (modes, First / Last, Knockout, Masks, Extend parent). They count as *Decorations* (visibility, statistics, LOD, export). The former *Decoration* generator was removed: old projects that contain one open without it (its children are re-attached to its parent); use Decal (flat patches), Fin (flaps) or Leaf / Mesh with Material rows for moss, lichen and mushrooms.

- **Decal** wraps a flat patch onto the bark: knots, lumps, cavities, scars. **Mesh > Size** (+ % of the parent radius, Aspect, Resolution, Mesh LOD offset), **Decal** (Rotation, Random rotation, Offset above the skin against z-fighting, Edge fade), **Height** (extrudes the height map of the decal's material, or the alpha of its normal map; negative values dig a cavity; flat when the material has no height map), **Material > Type** (weighted list, seasons), **LOD**. The patch follows the parent's wind exactly.
- **Fin** is a thin flap for fungus, moss and lichen: **Fins** (Size, Width, Flip, segments), **Orientation** (Style Perpendicular / Along spine / Up, Start angle, Roll), **Deformation** (Fold, Curl, vertex Amount / Noise scale / Seed, Scale X / Y / Z), **Lighting** (Puffiness, Match surface), **Wind > Ripple scale** (the base keeps the parent's wind, the tip gets its own flutter - the flap never tears off), **Material > Type**, **LOD**.
- **Cutout meshes.** The **Material** tab *Type* list (Material / Mesh / Weight rows) works as on Leaf: a row whose material owns a cutout mesh (*Any*, *Primary* or a specific mesh) gives the decal / fin the **cutout's outline**; a row set to *None* (or a material without meshes) builds the plain grid. A cutout is refined to the Resolution (decal) or Width / Length segments (fin) and then projected / mapped like the grid, so decals still hug the bark and the height map still extrudes them (the height fades to 0 along the cutout outline); fins keep zero gap where they touch the bark. The cutout's anchors are exported, so a Leaf or Mesh node below a Decal / Fin can be planted on them.
- Procedural starter maps (knot / burl patch, lichen flap, fungus shelf) are generated by `surfaceDetailMaps` in `src/presets/procTextures.ts`; the colour alpha is the cut-out, the normal alpha is the height.

## Leaf collision removal
Select the **Tree** node > **Collision** tab. **Leaf collision removal**: *None* (off, default) · *Low* (leaf against leaf, spheres, fastest) · *Medium* (all collisions: boxes for leaves, skeleton capsules for branches) · *High* (exact triangle intersection with the leaves and the real branch triangles, slowest). *Use spherical tests on leaves* tests every leaf as a sphere (faster, keeps more leaves); *Cluster plane overlapping* applies the same tests to Batched leaf cards in the top-down XY plane only.
The pass runs after all nodes are evaluated: the plain tree appears first and the result pops in when the pass is done; it restarts whenever the leaves change and is cancelled by the next edit. At a coarser LOD the tests are one step cheaper.
Each **Leaf / Batched leaf** has **Post > Collision**: *Priority* (higher wins, curve along the parent, ties go to the earlier leaf), *Sphere threshold* (0.1 - 2, scales the test sphere), *On collision* (Remove / Shrink / Move away along the normal), *Test against* (All / Same generator / Other generators) and *Parent* (Remove parent reports twigs that lost all leaves). A leaf never collides with the branch it grows from. The viewport statistics show how many leaves were removed.

## Seasons
The **Season** slider (0 – 1) is on the viewport toolbar (calendar button, popover with the slider and the two dropped-leaf checkboxes; arrow keys step 0.01, PageUp / PageDown 0.1). It is also in *Window ▸ Lighting* and on the **Tree** node (**Season** group). Every change is one undoable step (a drag merges) and regenerates the model; the value is saved in the `.ktree`, the project settings and the export manifest. It is a *selector*, not an animation: it only changes the probability that a material is chosen.
- **Per node.** Branch, Trunk, Root, Leaf, Frond, Knot, Decal, Fin and Mesh have **Material > Season**: *Start offset* (0 = immediately, positive = later, negative = earlier), *Time scale* (1 = one year, 0 = never changes) and, on structure nodes, *Descendant offset* (shifts the node and everything below it, so twigs can change after the trunk). Branch also has *Gravity*: the branch droops by Gravity x its transition value. Leaves also have *Drop time*. Variance randomises per element (seeded, deterministic); the curve runs along the parent.
- **Materials.** Each material has a **Season curve** (Materials panel > Main > Season); a **Material Set** groups materials (one set per season) and may override all member curves with **Override season**. The chance of a member = member weight x curve value at the node's transition value. Every material stays assigned; only the probabilities move. Leave the curves flat and the offsets at 0 and the slider changes nothing.
- **Dropped leaves.** *Show dropped leaves* (Tree or toolbar) lays the leaves whose transition reached *Drop time* on the ground (z = 0, random yaw, *Fallen > Spread*). They are not moved by wind. *Export dropped leaves* adds them to the export (off = viewport only).
- **Season forces.** Attach **Season Light** (leaves growing towards the arrow change sooner) or **Season Wind** (dropped leaves are swept along the arrow by *Distance*) to a Leaf node like any other force; select the force node to see its arrow in the viewport.
- **Presets.** Oak, Maple and Birch (and the Realistic Oak / Birch) ship Spring / Summer / Autumn / Winter leaf and bark materials in two Material Sets; move the slider to see them.

## Vertex colours

- **Tree > Vertex Color > Compute / Packing.** *Legacy* (default): vertex RGB = bark tint x ambient occlusion. *Kekenik*: R = random tint per branch, G = height along the plant (0 base .. 1 top), B = ambient occlusion (baked when the export bakes AO). Use the channels as masks in a shader (variation, age, AO).
- **Generator > Skin > Vertex color** (Branch, Trunk, Root, Knot): *Mode* Inherit (default) / Multiply / Set / Add with *Color*; *Variance* varies brightness per branch; *Seamless* continues the parent colour exactly at the attach point; *Profile* (along the branch) and *Parent curve* (along the parent) scale the effect, e.g. lighter young twigs or a darker trunk base.
- **Generator > Material > Vertex Color** (Leaf, Frond, Decal, Fin, Cluster): the same *Mode* / *Mode color* / *Seamless* / *Profile* (along the item) / *Parent curve*; the existing *Variance* randomises each item. Each item also gets its own random tint for the Kekenik R channel.
- **Viewport:** Vertex color, Vertex color R / G / B (Alt+Shift+R / G / B) and Ambient occlusion (Alt view menu) inspect each channel.
- **Export:** the chosen packing goes into COLOR_0 (glTF) and the colour columns of OBJ / PLY; *Bake AO > Bake AO into vertex colour B* writes the baked AO into B.

## Materials
Presets ship neutral generated maps. To use your own, open the **Materials** panel, select *Bark* or *Leaf* and drop an image on the *Color* (and *Opacity*, *Normal* …) slot. Maps are embedded in the `.ktree`.

## Library
* Search box and category chips filter the grid; *Save Current…* stores the open project as a user preset (local browser storage); *Import* / *Export* read/write `.ktree` files; the × button deletes a user preset.

## Projects
`Ctrl+N/O/S`, `Ctrl+Shift+S`. Unsaved work is autosaved and offered for recovery after a crash. Templates (*File ▸ Export Node Template…*) share sub-graphs.

## Preferences (Edit ▸ Preferences…)
UI scale · navigation scheme (Kekenik, Maya-like Alt-drag, Blender-like MMB) · autosave delay · performance mode (Low viewport preset) · language.

## Help
`?` or `F1` – shortcut cheat sheet · *Help ▸ Interactive Tour* · *Help ▸ Welcome Screen*.

## Troubleshooting
* Blank viewport: the browser needs WebGL2. Enable hardware acceleration.
* Slow: enable *Performance mode*, lower *Number* counts (yellow `!`), use LOD preview.
* A crash page shows a log – use **Copy log** and **Reload** (autosave restores your work).

## Forces

Force nodes attach to a generator (Forces port) and bend or steer its branches. Every force has **Strength** (with a curve along the branch), **Influence**, **Align strength**, **Indicator scale**, **Attenuation** (a sphere around a centre outside which the force fades to zero) and an optional **Volume** that generators can use as an Include / Exclude container. A generator's **Forces > Align** scalar multiplies each force's Align strength (how much forces change the initial orientation of its branches; 1 = unchanged).

Types: Gravity, Directional, Phototropism, Attractor (magnet), Vortex, Turbulence, Curl, Pull to Axis, Ground avoid, and:

- **Gnarl** - spirals spines around a world-space axis (Frequency, Irregularity, Seed).
- **Twist** - turns branches about their own growth direction into a helix (Turns, Phase).
- **Planar** - confines growth to a plane (Position, Normal, Softness); Strength is how hard.
- **Return** - steers branches back to their original direction; combine it with Gnarl / jinked branches.
- **Knockout** - removes nodes growing in the arrow direction (Strength = sensitivity: 0 none, 0.5 a hemisphere, 1 everything). It does not bend branches.
- **Geometry** - an imported Mesh asset (Position, Rotation, Scale) as an obstacle: **Force** Avoid / Attract / None (negative Strength reverses it) within **Range**; **Collide** None / Obstruct (branches slide along the surface and never enter it) / Prune (a branch is cut before its first intersection; its children go with it) / Stop (a branch ends exactly on the surface). The mesh should be closed (watertight). *Include in model* and *Ambient occluder* are stored but not used yet. The *Generators* source is not available yet.
